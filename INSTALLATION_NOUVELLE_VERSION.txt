DOSSIER 047 — AJOUT DES MÉDIAS SUR CHAQUE QR CODE

Cette mise à jour ajoute l'importation et l'enregistrement permanent des médias associés aux indices. Elle conserve les codes QR existants : aucun QR code n'a besoin d'être réimprimé.

FONCTIONNALITÉS
- Chaque indice peut rester en texte seul ou présenter une photo, un audio, une vidéo, une carte via URL ou un document PDF.
- L'administration permet d'importer une photo, un audio, une vidéo ou un PDF (50 Mo maximum).
- Les fichiers sont stockés dans le bucket public Supabase Storage « dossier047-media ».
- Le lien du fichier et le type de média sont enregistrés dans la fiche de l'indice via game-api.
- Après scan, le média apparaît avant la consigne. Un bouton « Revoir le média » permet d'y revenir.
- Remplacer un fichier ne supprime pas automatiquement l'ancien : cela évite de casser un affichage en cours et permet un retour arrière. Les anciens fichiers pourront être nettoyés plus tard depuis Supabase Storage.

INSTALLATION — DANS CET ORDRE

1) SAUVEGARDE
Télécharger une nouvelle sauvegarde du dépôt GitHub avant de remplacer les fichiers.

2) MIGRATION SQL 004
Dans Supabase > SQL Editor > New query, ouvrir et copier tout le fichier :
supabase/migrations/004_stockage_medias_qr.sql
Coller dans l'éditeur et cliquer sur Run. Cette migration crée/met à jour le bucket et ses règles d'accès. Ne pas rejouer les migrations 001, 002 ou 003.

3) METTRE À JOUR GITHUB
À la racine du dépôt, remplacer : app.js, styles.css, index.html, README.md et INSTALLATION_NOUVELLE_VERSION.txt.
Ajouter le nouveau fichier supabase/migrations/004_stockage_medias_qr.sql.
Remplacer aussi supabase/functions/game-api/index.ts par celui de cette archive.
Publier les changements sur la branche main avec Commit changes.

4) REDÉPLOYER game-api
Dans CMD, à la racine du projet contenant le dossier supabase, exécuter :
supabase functions deploy game-api
Le projet est déjà lié si la commande supabase link avait été faite auparavant. Ne jamais placer la clé service_role dans le navigateur ou GitHub.

5) TESTER
- Ouvrir le site et faire Ctrl+F5.
- Se connecter à l'administration > Énigmes & médias > Modifier un indice de test.
- Choisir une photo, audio, vidéo ou PDF puis cliquer Enregistrer.
- Vérifier que l'indice affiche le type et le lien du média dans l'administration.
- Scanner le QR code correspondant sur un téléphone : le média doit apparaître avant la consigne.
- Cliquer « Revoir le média », puis actualiser et scanner à nouveau.
- Vérifier que le média est toujours présent.

LIMITES ET SÉCURITÉ
- Taille maximale d'un fichier : 50 Mo.
- Types pris en charge : JPEG, PNG, WEBP, GIF, audio MP3/MP4/WAV/OGG/WEBM, vidéo MP4/WEBM/MOV et PDF.
- La lecture est publique afin que les joueurs puissent voir les médias sans compte. L'envoi et la gestion des fichiers sont réservés aux administrateurs authentifiés.
- La clé publishable peut rester dans config.js. Ne jamais publier la clé service_role / sb_secret.
- Une carte peut être ajoutée comme URL dans le champ URL du média ou URL de carte. Une carte image/PDF peut aussi être importée comme média.
